# 教練職涯史 —— 交付提示詞(B 層:教練過往戰術風格)

> 給協作方(有網路的 AI 或人)的完整任務說明。交回來的檔案放
> `epl/data/manual/coach-careers.json`(收件匣),由本站核對後才發布。
> 這是三層風格構想的 B 層:A 層(近 10 場位移)已上線,
> B 層要回答「換帥的球隊,新教練**過去**是怎麼帶隊的」。

## 為什麼只要「任期」不要「數據」

本站已握有逐場統計(英超/英冠 2023-24 起、西甲 2024-25 起,
football-data.co.uk 季檔;其他歐洲主要聯賽同站也有靜態季檔可補抓)。
**只要知道教練前一段任期「在哪一隊、從哪天到哪天」,風格數據我們自己算** ——
這樣交付內容最小、可核對性最高,也避免交付數據本身造假的風險
(本專案實測過:交付檔自報全過、獨立核對抓出幾十筆錯)。

## 任務

對下列 **64 隊的現任教練**(名單見附錄),每人交付:

1. **現任這份工作**的起始日(我們手上有一部分,當交叉核對用 —— 請照實查,不要抄本站)
2. **前一段一線隊總教練工作**(最多往前兩段):球隊、國家、聯賽、起訖日
3. 每一段附**兩個獨立來源網址**(維基百科可以當其中一個,另一個要是媒體報導或俱樂部官方公告)

只算「一線隊總教練 / head coach」。助教、青年隊、代理(caretaker)不算,
但**代理後轉正**的以轉正日為準、並在 `note` 註明。國家隊算(照樣記)。
第一次執教一線隊的(例如從助教直升),記 `firstHeadCoachJob: true`,前段留空。

## 交付格式

```json
{
  "deliveredAt": "2026-09-01",
  "preparedBy": "(誰整理的)",
  "coaches": [
    {
      "league": "pl",
      "team": "LIV",
      "name": "Andoni Iraola",
      "current": { "club": "Liverpool", "from": "2026-06-01",
        "sources": ["https://...", "https://..."] },
      "previous": [
        { "club": "Bournemouth", "country": "England", "competition": "Premier League",
          "from": "2023-06-19", "to": "2026-05-30",
          "sources": ["https://...", "https://..."] },
        { "club": "Rayo Vallecano", "country": "Spain", "competition": "La Liga",
          "from": "2020-08-04", "to": "2023-06-16",
          "sources": ["https://...", "https://..."] }
      ],
      "firstHeadCoachJob": false,
      "note": ""
    }
  ]
}
```

- 日期至少到月(`YYYY-MM`),查得到就給到日。**查不到就寫 null,不要估**。
- `competition` 用該聯賽通用英文名(Premier League、La Liga、Bundesliga、
  Serie A、Ligue 1、Championship、Eredivisie…),不要自創縮寫。
- 名字照俱樂部官方寫法(帶變音符號)。

## 我們會怎麼核對(照實寫,讓你知道哪些偷懶會被抓)

- **現任起始日**:跟本站逐日核對的官方名冊比(英超每天對官方)。對不上整筆退回。
- **任期 vs 聯賽成員資格**:宣稱某季在某聯賽帶某隊,那隊那季就必須真的在那個聯賽
  (本站有英超/西甲/英冠逐季賽果)。Leeds 2024-25 在英冠 —— 這種錯上次交付出現過。
- **任期重疊**:同一人兩段任期日期重疊 = 至少一筆是錯的,同區塊整批不採用。
- **新聞語料**:本站的新聞存檔會查教練名字與球隊的共現。
- 同一(聯賽+球隊)區塊裡只要有一筆被證明是錯的,**整區塊不採用**
  (挑通過的用等於在對不上的來源裡選喜歡的答案)。

## 交回來之後(給接手 AI 的計畫,協作方不用做)

1. 寫 `scripts/verify-coach-careers.mjs`:上述核對 + sha256 守門,
   產 `data/coach-careers-verified.json`,build 只讀後者(比照租借與英冠教練的流程)。
2. 對核對通過的前任期:任期落在本站已有逐場 CSV 的聯賽賽季
   (E0/E1 2023-24 起、SP1 2024-25 起)→ 直接算該任期的逐場風格
   (lib/style-trend.mjs 的同一套欄位);德甲/義甲/法甲等 → football-data.co.uk
   有同格式靜態季檔(D1/I1/F1),在 CI 補抓(靜態檔下載,不是爬站)。
   沙烏地、MLS、巴西等沒有涵蓋的 → **只列任期事實,不算風格、不留空欄位**。
3. 畫面:教練卡加「此教練前一段任期」區塊,標明球隊、期間、場次與逐場風格
   (10 級分,池 = 該聯賽該期間的全部球隊)。**跨聯賽的級分不可比**,
   畫面要寫「級分是他當時那個聯賽裡的位置」。球隊風格 ≠ 教練風格,
   這句也要寫在畫面上(鐵則四:推論要標註)。
