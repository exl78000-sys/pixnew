## 任務

下面列了英超、西甲、英冠共 64 隊(其中一隊是雙教頭)。對每一隊的**現任總教練**,查出:

## 規則

- 只算一線隊總教練。助理教練、青年隊/B 隊教練、看守教練(caretaker)不算;
  但「看守後轉正」算,以**轉正日**為準,並在 note 註明。國家隊總教練算,照樣記。
- 這是他第一份一線隊總教練工作的話,寫 "firstHeadCoachJob": true,previous 給空陣列。
- 日期至少到月(YYYY-MM),查得到就給到日(YYYY-MM-DD)。**查不到的欄位寫 null,
  不要推測、不要用「大約」**。寧可 null 也不要錯。
- 每一段工作附**兩個來源網址**:維基百科可以當其中一個,另一個要是
  媒體報導、俱樂部官方公告或聯賽官網。兩個來源要真的講到這段任期。
- 名字照俱樂部官方寫法,保留變音符號(例如 Vítor、Hürzeler)。

## 二、內部筆記(不要貼給協作方)

### 為什麼只要任期不要數據

本站已握有逐場統計(英超/英冠 2023-24 起、西甲 2024-25 起,football-data.co.uk
季檔;德義法等歐洲主要聯賽同站有同格式靜態季檔可在 CI 補抓)。只要任期,
風格數據自己算 —— 交付內容最小、可核對性最高,也避免交付數據造假
(實測過:交付檔自報全過、獨立核對抓出幾十筆錯)。

零交付的路已量過走不通(2026-08-29):SportMonks 教練詳情 20 筆全被訂閱
擋掉(0 成功);自家三聯賽名冊的 spells 只覆蓋 2/67 位現任教練的前任期
(Nuno:NFO→WHU)。

### 收件與核對計畫(給接手 AI)

收件匣:`epl/data/manual/coach-careers.json`。寫 `scripts/verify-coach-careers.mjs`:

- **現任上任日**:對本站逐日核對的官方名冊(英超每天對官方)。對不上退回該筆。
- **任期 vs 聯賽成員資格**:宣稱某季帶某隊踢某聯賽,那隊那季就必須真的在
  那個聯賽(本站有英超/西甲/英冠逐季 results.json)。Leeds 2024-25 在英冠 ——
  這種錯在租借交付出現過。
- **任期重疊**:同一人兩段日期重疊 = 至少一筆是錯的。
- **新聞語料**:名字與球隊在本站新聞存檔的共現(report-only)。
- **區塊級退回**:同一聯賽的紀錄有一筆被證明是錯的,整聯賽退回
  (挑通過的用 = 在對不上的來源裡選喜歡的答案)。
- sha256 守門比照租借與英冠教練:產 `data/coach-careers-verified.json`,
  build 只讀後者。
- Nuno 的 NFO 任期(2023-12-20 ~ 2025-09-09)本站自己有,是現成的控制題。

### 交回後的實作

1. 核對通過的前任期:任期落在已有逐場 CSV 的聯賽賽季(E0/E1 2023-24 起、
   SP1 2024-25 起)→ 用 `lib/style-trend.mjs` 同一套欄位算該任期的逐場風格;
   德甲/義甲/法甲 → football-data.co.uk 靜態季檔(D1/I1/F1)在 CI 補抓。
   沙烏地、MLS、巴西等沒涵蓋的 → **只列任期事實,不算風格、不留空欄位**。
2. 教練卡加「此教練前一段任期」區塊:球隊、期間、場次、逐場風格
   (10 級分,尺 = 該聯賽該期間的全季分布)。**跨聯賽級分不可比**、
   **球隊風格 ≠ 教練風格** —— 兩句都要寫在畫面上。
