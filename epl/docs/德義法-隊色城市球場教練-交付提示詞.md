# 德甲 / 義甲 / 法甲:隊色、城市、球場、教練 —— 交付提示詞

> **2026-10-09 更新**:隊色、城市、球場、容量已改由 FotMob 球隊頁供,這份提示詞現在**只剩教練(與綽號)需要交付**;球隊資料那幾欄不必再交。

把這份連同 `docs/交付格式-德義法球隊與教練.md`(規格與核對規矩)一起交給交付方。**交付方不能憑記憶填**:每一格有值都要附能點開的網址,不確定就給 null(鐵則三、五)。

## 任務

對下列每個聯賽的**本季(2026-27)球隊**,交付兩份 JSON:

1. 球隊資料:隊色(球衣主色在前)、城市(中文)、球場(中文 + 原名)、容量(整數)、暱稱
2. 現任總教練:原文拼寫姓名、上任日期(不確定就不給)、出處

隊碼必須用下表的 `code`,不要自己編。收件匣路徑:`data/manual/{bundesliga,serie-a,ligue-1}-{teams,coaches}-delivery.json`。
