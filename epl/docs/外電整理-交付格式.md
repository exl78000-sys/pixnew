# 人工整理外電 —— 交付格式與累積機制

## 一句話

**每次交付一份「這一週」的檔案就好,不用把舊的附上。**
本站會自己併進檔案庫,舊的不會被蓋掉。

---

## 一、交付檔放哪裡、長什麼樣

放到 `epl/data/manual/news-curated.json`(整份覆蓋,格式不變):

```jsonc
{
  "source": "Web research",
  "retrievedAt": "2026-08-28T00:00:00+08:00",
  "window": { "from": "2026-08-22", "to": "2026-08-28", "timezone": "Asia/Taipei" },
  "note": "……",
  "stories": [
    {
      "id": "pl-match-review-20260823-sunday-wrap",   // 必填,全站唯一
      "competition": "pl",                            // pl / es1 / ucl
      "competitionName": "英超",
      "type": "match-review",                         // match-review / news / transfer-news
      "date": "2026-08-23",                           // 必填,YYYY-MM-DD
      "title": "……",
      "body": "……",                                   // 繁體中文摘要(人寫的,不是機器翻譯)
      "matches": [{ "home": "Manchester City", "away": "Bournemouth", "score": "2-1" }],
      "status": "reported-saga",                      // 見下方對照表
      "source": "Premier League 官方",
      "link": "https://……"                            // 必填,https
    }
  ]
}
```

### `window` 是「你搜尋的期間」,不是「新聞的日期範圍」

這一欄決定畫面上會怎麼講涵蓋範圍,所以**一定要照實填**。
本站把每次交付的 `window` 合起來,連續的併成一段、**中間沒交付的講成斷檔**:

> 涵蓋範圍:共 41 則、3 次整理,累計 18 天。8/22 ~ 8/28、9/12 ~ 9/21。
> **中間有 1 段沒有人整理**:8/29 ~ 9/11 —— 那幾天不是沒有新聞,是本站沒有收。

把 `window` 填寬(例如整個月)但只交了一週的內容,畫面就會宣稱收了一個月 —— 那是編出來的涵蓋範圍。

### `id` 決定去重

- **新的一則** → 用沒出現過的 id。
- **要更正先前交過的一則** → 用**一樣的 id** 再送一次,內容會被蓋掉,
  但「第一次收到是哪天」會保留。

### `status` 對照表(只有這六個有語意)

| status | 畫面上顯示 |
|---|---|
| `official-overview` | 官方整理 |
| `completed-transfer-follow-up` | 已完成的交易 |
| `reported-saga` | 媒體報導,非已完成 |
| `reported-targets` | 媒體報導的目標,非已完成 |
| `mixed-official-and-reported` | 官方與傳聞混合,逐條看狀態 |
| `club-market-analysis` | 球會動向分析 |

沒見過的 status **不會**被猜成某一類,原樣留著並在建置時報出來。
需要新的分類就講一聲,加進對照表再用。

## 二、比分會被逐場核對,對不上的整則不出

`matches` 裡的每一場,本站都會拿自己的賽果比對,**每次建置都比一次**
(賽果會更新,只比一次的話哪天不一致沒人會發現)。

- 全部對得上 → 標「比分已與本站賽果逐場核對」
- 本站沒有那一輪的資料(例如歐冠附加賽)→ 標「本站沒有這一輪的資料,比分無法核對」
- **對不上 → 整則不出**,並在建置 log 裡列出差在哪

檔案裡自己寫 `"verified": true` 不算數 —— 那是交付方自己說的。

比對用**報導日期前後 5 天**收斂到對的那一場。同一組對戰跨季會重複,
不收斂的話會配到上一季那一場(踩過:西甲三則賽報因此全被誤判成比分不符)。

## 三、本站這邊怎麼收

```
data/manual/news-curated.json          ← 你交付的(收件匣,整份覆蓋)
data/manual/news-curated-archive.json  ← 累積下來的(檔案庫,自動產生,不要手動編輯)
```

```bash
npm run news:merge            # 收件匣 → 檔案庫(依 id 去重、記 firstSeen、淘汰 180 天前的)
npm run news:merge -- --dry-run
npm run news:merge -- --keep-days=365
```

排程每次執行都會跑這一步。**內容沒變就完全不寫檔**,所以不會產生雜訊提交。

`build` 讀的是**檔案庫疊上收件匣**(同一個 id 以收件匣為準),
所以新交付一落地就看得到,不必等合併那一步跑完。
