## 2026-08-31：升班隊補上「上一季在原聯賽」的成績

- 升班隊在新聯賽的 `lastSeason` 是空的，球隊頁上季區塊整塊空白 —— 但那一季的
  資料本站其實有，躺在原聯賽目錄裡（COV／IPS／HUL 2025-26 在英冠）。
- 新增 `lib/prev-league.mjs`（兩個 build 共用，不各寫一份），輸出
  `teams[].lastSeasonElsewhere`，形狀與 `lastSeason` 完全相同（同一支 `buildTable`），
  前端因此整塊重用，只換標題並加警語。
- 名次用**原聯賽全隊**排（只排缺的那幾支會讓冠軍變成「第 1 名」但失去意義），
  並沿用英冠自己的規則排除升級附加賽，數字才跟英冠站上一致。
- 畫面明寫三件事：這是哪一季哪個聯賽、名次與積分**不可跨聯賽互比**、
  **模型沒有拿這些數字換算**（升班隊仍用聯盟後段先驗，踢滿幾場才改用本季實際表現）。
- 目前結果：COV 英冠第 1（95 分）、IPS 第 2、HUL 第 6（附加賽升級）。
- 西甲與英冠的升班隊來自西乙／英甲，本站沒有那兩個聯賽，維持照實顯示「上季不在這個聯賽」。

## 2026-08-31：實時頁「開賽倒數」移到最上面

- 版面順序改為：開賽倒數 → 進行中 → 剛結束 → 還沒有賽果 → 已完賽 → 積分榜。
- 理由：這一頁最常被用來回答「下一場什麼時候踢」，而倒數原本壓在三個區塊下面；
  沒有比賽的日子要捲很久才看得到，那正是最常見的使用情境。
- 同步修掉兩處會說謊的文案（原本寫「下方的開賽倒數」，位置已變）。

## 2026-08-31：進球認領改白名單（收口）

- `goalsOf()` 的認領資格由「排除已知非進球型別」改為「必須看得出是進球」：
  型別在 `G/O/P/OG` 或 description 在 `G/P/O` 才有資格認領比分變化。
- 原因：黑名單擋不掉沒見過的代碼。紅牌 `R` 不在黑名單、又帶 `personId`，
  真正的進球事件若剛好缺 `personId`（烏龍球有此形狀），同一比分下的紅牌會勝出，
  射手被安到吃牌的人身上 —— 而品質檢查抓不到，因為 `person` 不是 null 只是錯的人。
- 認不出是進球時保留 null，交由完賽品質檢查退避重抓（配錯人比配不到糟）。
- 新增兩條回歸測試：無射手烏龍球撞同比分紅牌、未知代碼不得認領。
- 實測目前 61 顆進球型別全為 `G/O/P`，白名單 100% 覆蓋，無回歸。

## 2026-08-31：修復完賽進球事件造成的自動部署阻塞

- 修正同一比分下 `PE` 早於 `G` 時，完場標記被誤判為進球的問題。
- 進球事件選擇排除牌、換人與半場起訖，並優先採用有射手的正式進球事件。
- 新增完賽資料品質檢查：進球數、最後比分、射手完整性。
- 新增 2 分鐘至 12 小時的分級退避重試，避免錯誤完賽快取永久凍結，也避免比賽日高頻重打。
- 新增對應回歸測試，包含真實事故形狀「`PE` 比同比分 `G` 早寫入」。
- 重新同步官方資料，修復 `CHE|BHA` 最後一球射手為 Pascal Groß（personId 22542），並補齊
  `MUN|IPS` 的品質資訊。
- 新增 `docs/賽事自動更新-故障處理.md`，記錄原因、恢復指令、品質代碼與後續混合式架構方向。

## 2026-08-31：支援歐冠新球季從抽籤資料切換為正式賽程

- `football-data.org` 開放 2026-27 正式賽程後，改由主來源的 144 場日期與主客資料顯示，不再沿用
  FotMob 抽籤檔的佔位日期。
- 尚未開賽、淘汰賽名單尚未產生時，晉級區間、球隊結局與冠軍維持未知，不按既有賽制硬推。
- 修正球隊輪次表把所有尚未出賽球隊標成「奪冠」，以及 Obsidian 匯出讀取空晉級區間而中止的問題。
- 測試改為區分「已發布賽程」與「已完賽球季」：PK、冠軍、完整第二來源核對只對完賽球季要求；
  未完賽球季仍要求不採用核對失敗的球員榜。
- 文件中的歐冠隊徽涵蓋率改為同時核對分子與分母；目前各季共 65 支不重複球隊，55 支有隊徽。
