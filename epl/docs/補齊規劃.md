## 階段 2 —— 西甲資料(進行中)

### 已完成:球員

`players` 從 0 補到 946 筆,球員頁與八個榜單上線。

**原本規劃寫的路是錯的,已由實測推翻** —— 詳見下面「已經試過而不通的路」。
現在走 Understat,一季一個請求(`npm run laliga:players`,已接進 `epl-live.yml`)。

**界線**:Understat 沒有背號、頭貼、出生日期、傷停、防守數據。
西甲球員頁因此**不是**英超那一頁的複製品,頁首直接列出缺什麼。
不要為了版面對齊補空欄位或估計值。

### 戰術頁:已經開了(FotMob)——**不要重做**

**這一節原本寫「先確認做得到哪一半再動手」,已經過期。**
平行的工作在預設分支上用 **FotMob** 解掉了:

- `scripts/fetch-laliga-lineups.mjs` —— 小批量快取已完賽的正式先發與陣型
- `scripts/probe-laliga-lineups.mjs` —— 它自己的探測
- `page-tactics.js` —— 西甲版戰術摘要
- `core.js` 的 `LEAGUES.es1.open` 已加入 `tactics`,守門條件改成 `ESSENTIAL.tactics = ['tactics']`

注意 `shapes.json` 仍然是 `{}` —— 它走的是**球隊層級**那條路(`tactics.json` +
FotMob 陣型),不是我原本規劃的逐場 `shapes`/`lineups`。兩者不衝突,但別搞混。

### 兩個來源的分工(已定案)

| | FotMob | SportMonks |
|---|---|---|
| 性質 | 網站公開端點,**腳本檔頭自己註明「不是穩定的官方 API」** | 付費訂閱,官方 API |
| 額度 | 每日硬上限 20 次 | 每小時 2000 次 |
| 補完整季 380 場 | 約 19 天 | 一次跑完 |
| 現況 | **已上線** | 已實測,adapter 未寫 |

**決定:FotMob 保留當主力,SportMonks 只補它給不了的。**
理由是不要換掉一個已經能動的東西;等 FotMob 哪天真的不穩了再談替換。

所以 SportMonks 接下來只做**球員欄位**:

1. 背號 `jersey_number`、頭貼 `image_path`
2. 生日、身高、體重、國籍
3. 隊長、合約起訖

這三項目前西甲球員頁明確標示「沒有」(`leaders.missing`),
補上之後把那幾行從 missing 裡拿掉 —— 標示要跟著資料走,不能留著騙人。

**界線不變**:西甲沒有 pulselive 那種「開賽前一小時公布正式名單」的來源。
賽前那一份永遠是推估,畫面上要跟英超的「官方」標籤分得開。

### 可平行做:教練名冊

`data/manual/coaches.json` 是人工維護的,裡面的戰術註解是針對「那一位教練」寫的。
西甲的名冊目前是空的。`npm run coaches:check` 只做 Wikidata 比對,不會**產生**名冊。
要補就是人工寫,或只放 Wikidata 查得到的事實(姓名、上任日期)而**不寫戰術註解**。

### 對照:哪些是 Understat 給不了的

### 尚未解決:傷停

四個候選路徑全部 404(**不是 403** —— 路徑問題不是權限問題):

```
/football/injuries                          → The requested endpoint does not exist
/football/sidelined                         → 同上
/football/sidelined/teams/{id}              → 同上
/football/squads/teams/{id}?include=player.sidelined
    → The requested include 'sidelined' does not exist on Player
```

最後一句最有價值:SportMonks 自己說 `Player` 上沒有 `sidelined` 這個 include。
**要查它官方文件的正確名稱再試,不要再靠猜多燒幾輪。**

不擋路:英超的傷停走 FPL,西甲少這一項不影響戰術頁與球員頁。

### 寫 adapter 之前還要做的一件事

`lineups` / `formations` **確認拿得到,但欄位形狀還沒讀**(探測只驗證了非空)。
寫 adapter 前先把那兩個陣列的欄位印出來 —— 這個專案的規矩是不憑印象斷言欄位。

## 已經試過而不通的路(不要重跑)

寫在這裡是為了讓下一個人不必重走一遍死路。每一條都是實測,不是推測。

### API-Football:Free 方案不含本季與上季

```
GET /status → 方案:Free・今日請求 0/100
GET /fixtures?league=140&season=2026&status=FT-AET-PEN
GET /players?league=140&season=2026&page=1
→ 200 {"errors":{"plan":"Free plans do not have access to this season,
        try from 2022 to 2024."}}
```

`league=140` 的 2025 與 2026 兩季**完全拿不到**。不是額度問題,是方案不含這些賽季。
西甲賽後資料 `0/11` 也是同一個原因 —— 不是還沒抓到,是拿不到。

換一個涵蓋本賽季的方案之後**程式會自己恢復**:抓取端撞到 plan 錯誤時把原因寫進
賽後存檔的 `blocked`,拿得到清單就清掉。build 與前端都照它說的講,不必改碼。

重跑探測:`npm run probe:laliga-players`(硬上限 5 個請求)。

### Understat:資料不在 HTML 頁裡

```
GET understat.com/league/La_liga/2025     → 200 但只有 18 KB,一個資料變數都沒有
GET understat.com/team/Arsenal/2025       → 同上
GET understat.com/getLeaguePlayers/La_liga/2025 → 404(這個路由不存在)
```

**能用的是獨立的 XHR 端點**:

```
GET  understat.com/getTeamData/{隊}/{年}          → 球隊整季(進球情境就是這裡來的)
POST understat.com/main/getPlayersStats/
     body: league=La_liga&season=2025            → 整季 600 名球員,一個請求
```

找到第三個的關鍵:不帶參數打 `main/getPlayersStats/` 回的是
`{"error":{"error_code":4}}` —— **回結構化錯誤而不是 404,代表端點在、只是少參數**。
在前兩個候選就下結論「Understat 拿不到球員資料」就會錯過。

重跑探測:`npm run probe:laliga-playerdata`(硬上限 6 個請求,單線間隔 1.5 秒)。

### SportMonks:傷停端點還沒找到

四個候選全部 404,詳見上面「SportMonks」那一節。
重點是 **404 不是 403** —— 端點名字的問題,不是方案不含。
查到正確名稱之後補上,不要重跑同樣這四個。

### 探測腳本自己踩過的兩個坑(寫在這裡免得重犯)

1. **取樣場次要用「確定已完賽」的。** SportMonks 第一輪用 `per_page=1` 拿到賽季第一場,
   `lineups`/`events`/`statistics` 全空 —— 但那只是「還沒踢」。差一點就據此
   判定「這個方案給不了逐場名單」,那會直接砍掉西甲戰術頁這條路。
   改用已完結的上一季取樣之後,兩個都有資料。

2. **判讀結論不要寫死在腳本裡。** 第一輪最後印的四行「判讀重點」是預先寫好的,
   其中兩行跟實際結果相反(寫「聯賽都不在」「本季不在」,實際上都在)。
   log 是下一個人唯一看得到的東西,寫死的結論會直接誤導他。
   現在改成依實際結果產生,而且「無法判定」要明講是無法判定。

## 不做的事(同樣重要)

- **單一進球的球員級「進球方式」** —— Understat 給的是球隊整季摘要,
  把某一類掛到某位球員的某一顆球是我們沒有的資料。球員逐球表不要加那一欄。
- **把沒通過驗收的特徵放進模型** —— 近五戰與交手紀錄的係數是 0,
  `npm test` 有一條專門守著。直覺上該有用不是理由。
- **大量爬網站** —— 靜態檔下載沒問題,官方進球事件是零額外請求。
  一場一個請求的做法先不要做。探測腳本自己也有請求硬上限。
- **為了畫面好看補測試資料** —— 要真實數字就在有 Secret 的 runner 上跑,
  不要寫假資料進正式快取。
- **拿賽後重建的模型冒充賽前預測** —— 沒有賽前快照的場次,`prediction` 就該是 `null`。
- **留一個永遠空白的欄位** —— 比不做更糟,讀者會以為是壞掉。
  拿不到就在畫面上說拿不到,並說明是「拿不到」還是「還沒到」。
