# 資料來源探勘 —— 交付提示詞(2026-08-29 發出)

第一節直接複製給協作 AI;第二節內部筆記。

---

## 一、複製這段給協作方

````
你是一個做資料來源調查的助手。請大範圍搜索,幫我找下面幾個缺口的**免費、
可程式化存取**的資料來源。這次的任務是**找來源,不是搬數據** ——
你交回來的每個網址我都會逐一發請求實測,所以:

- **只交你真的打開看過的網址。** 上次交付有人按格式捏造網址,41 個 404,整批退件。
- 每個來源要附一小段**你實際看到的資料樣本**(欄位名或幾行內容),證明你真的看過。
- 找不到的缺口照實說找不到,並列出你查過哪些地方 —— 「查無」是有價值的答案,
  編一個來源是毀滅性的答案。

## 要找的缺口(依優先順序)

**A. 逐場的球隊層關鍵傳球(key passes)或 xA** —— 英超與西甲,2025-26 起逐場。
   已有:Understat 的球員「整季」xA(不夠,要逐場);FBref 之類有沒有球隊逐場
   的 KP/SCA?要能批次取得(靜態表格頁也行,說清楚怎麼解析)。

**B. 逐場的定位球 xG 或定位球射門數** —— 英超與西甲,逐場。
   已有:Understat 的「整季」進球情境分類(OpenPlay/FromCorner/SetPiece...)。
   要的是同樣分類的**逐場**版本,或任何「這一場角球/任意球製造幾次射門」的來源。

**C. 英冠(EFL Championship)的球員層資料** —— 出賽分鐘、進球、助攻,最好逐場。
   已確認不行的(不要再交):Understat(實測不涵蓋英冠)、FPL(只有英超)。
   FBref?足球 API 的免費層?俱樂部官網的合計頁?

**D. 西甲與英冠的傷停/停賽名單** —— 要「目前誰缺陣」而且會更新的來源,
   可以每天程式抓。英超我們用 FPL 的狀態欄,這兩個聯賽沒有對應物。

**E. 這些聯賽的逐場比賽統計(射門/角球/牌,或 xG)**:
   瑞典 Allsvenskan、克羅埃西亞 HNL、沙烏地職業聯賽、墨西哥 Liga MX、巴西甲。
   已有:football-data.co.uk 涵蓋英/蘇/德/義/西/法/荷/比/葡/土/希,上面五個不在。
   用途是教練前任期的風格計算,涵蓋 2020 年之後即可。

**F. 英冠「扣分處分」的權威可程式來源** —— 歷年與當季(財政違規扣分等)。
   我們的積分榜是從比分算的,扣分要另外接。維基百科的表格頁可以,
   但要給出確切網址與表格位置。

**G. 英超/英冠「延賽與改期」的可程式來源** —— 比賽宣布延期時,
   有沒有 feed/頁面可以讓程式知道「這場改期了」而不是「資料落後」。

**H.(加分)逐場控球率與傳球成功率** —— 英超與西甲。

## 每個發現的交付格式

單一 JSON 檔:

{
  "deliveredAt": "YYYY-MM-DD",
  "preparedBy": "你的代號",
  "findings": [
    {
      "gap": "A",
      "source": "來源名稱",
      "url": "https://...(會被實測)",
      "coverage": "哪些聯賽、哪些賽季",
      "granularity": "逐場 / 逐輪 / 整季",
      "access": "靜態CSV下載 / JSON端點 / 要解析HTML表格 / 官方API免費層",
      "updateFreq": "每天 / 每輪 / 不明",
      "terms": "使用條款重點(能不能程式抓、有沒有流量限制、要不要註冊)",
      "evidence": "你實際看到的欄位名或幾行樣本(這一欄是必填)",
      "confidence": "high / medium / low",
      "note": ""
    }
  ],
  "notFound": [
    { "gap": "B", "searched": ["查過的網站/關鍵詞列表"], "conclusion": "為什麼判斷沒有免費來源" }
  ]
}

## 規則

- 免費優先;有免費層的付費 API 可以交,但 terms 要寫清楚免費層的限制。
- 一個缺口可以交多個候選,標 confidence。
- 不要交需要登入才看得到資料的來源,除非免費註冊即可,並在 terms 說明。
- 我這邊的核對:網址逐一實測、evidence 跟實際回應比對 ——
  上次的教訓再說一次:**寧可 notFound,不要編造。**
````

## 二、內部筆記(不要貼給協作方)

**背景**:位移雷達要跟主雷達完全同軸,差「傳球創造」與「定位球威脅」兩軸的
逐場來源(A、B);Understat 的 getTeamData `dates` 已探明有逐場 xG,
另外三軸(火力/終結/穩固)不用等這份交付就能做。C~H 是累積的已知缺口
(英冠球員層、傷停、教練任期聯賽、扣分、延賽)。

**收件與核對(給接手 AI)**:交回來先跑網址實測(比照
`data/manual/coach-profiles-urlprobe.json` 的做法,403/5xx 不當不存在);
evidence 跟實際回應抽樣比對;**這份交付不直接進任何產物** ——
它只是探勘,真正接資料前要照 `docs/接新API.md` 走 adapter + 獨立核對。
判定可用的來源記進 `docs/英冠-資料來源探測.md` 或對應的探測文件。
