把下面整段交給協作方。**不要**只轉述需求 —— 這份的重點有一半在
「什麼情況要回報 null」與「我會怎麼核對」,少了那兩段,交回來的東西我沒辦法採用。

## 給協作方的內容(以下整段複製)

### 你要做的事

補齊英格蘭冠軍聯賽(EFL Championship)36 支球隊的**球隊基本資料**。
這 36 支是 2023-24 至 2026-27 四個賽季裡出現過的所有球隊。

需要四類欄位:

| 欄位 | 說明 | 沒有把握時 |
|---|---|---|
| `colors` | 主場球衣的兩個主要顏色,hex,**主色在前** | 回 `null` |
| `city` | 主場所在城市(繁體中文) | 回 `null` |
| `venue` | 主場球場,格式是「中文名 English Name」 | 回 `null` |
| `capacity` | 該球場的座位數(整數) | 回 `null` |
| `nickname` | 球隊綽號(繁體中文),沒有廣為使用的就不給 | 回 `null` |

### 交付格式

一個 JSON 檔,結構如下。**`code` 與 `en` 照抄下面的清單,不要改**
—— 那是本站的鍵,改了就對不上。

```json
{
  "source": "你用了哪些來源(具體到網站名)",
  "retrievedAt": "2026-08-29",
  "teams": [
    {
      "code": "BIR",
      "en": "Birmingham City",
      "colors": ["#0000FF", "#FFFFFF"],
      "city": "伯明罕",
      "venue": "聖安德魯球場 St Andrew's",
      "capacity": 29409,
      "nickname": "藍軍",
      "sources": {
        "colors": "https://…",
        "capacity": "https://…"
      }
    }
  ]
}
```

`sources` 是**逐欄位**的出處網址。這一欄不是形式 ——
我核對時對不上的欄位會回去看你引的那一頁,引不出來的欄位一律不採用。

### 規則(這幾條會決定我採不採用)

1. **不確定就回 null,不要填一個看起來合理的值。**
   缺一格我可以在畫面上標「未取得」;填了一個錯的,讀者不會知道那是錯的。
   這是最重要的一條 —— 交回來 30 支正確 + 6 支 null,比 36 支裡混 3 支錯的好得多。

2. **座位數要寫「目前的」,不是歷史最高。**
   多數英冠球場近年整修過。如果你找到的頁面沒寫是哪一年的,回 null。

3. **顏色要是主場球衣的顏色,不是隊徽的顏色。**
   兩者常常不同(例:隊徽有金色描邊但球衣沒有)。
   單色球衣就只給一個顏色 + 一個對比色(通常是白或黑)。

4. **不要整批複製再改。**
   上一次交付的租借紀錄,2024-25 那一批是 2025-26 的複本、年份減一,
   17 組重覆裡 14 組「月日完全相同、剛好差一年」。這種東西我一定驗得出來,
   而且**驗出來的話整批不採用**,不是挑好的用。

5. **同一個區塊裡有一筆被證明是錯的,那個區塊我整批不採用。**
   從兩個對不上的來源裡挑一個喜歡的答案,等於沒有核對。

6. **你自己說「都檢查過了」不算數。** 我會用獨立來源再驗一次(下一節)。
   這不是不信任 —— 上一次交回來的進球明細自報「0 筆不符」,
   我拿另一個來源逐場核對,兩季合計 39 場對不上。

### 我會怎麼核對(先告訴你,你才知道什麼會被退)

- **顏色**:本站倉庫裡有這 36 支球隊的隊徽 PNG。我會抽出隊徽的主要顏色,
  跟你給的主色比對。**不要求一樣**(球衣跟隊徽本來就可能不同),
  但差太遠的我會回去看你引的出處;引不出來就不採用那一筆。
  另外會檢查兩個顏色在深色背景上的對比度與色盲可辨性 —— 太接近的我會請你補一個對比色。
- **座位數**:同一座球場在不同球隊的紀錄裡必須一致(有共用球場的情況)。
  另外會用「數量級」擋明顯的錯:英冠球場在 5,000 到 62,000 之間,超出範圍的一律退。
- **城市與球場**:跟本站已有的英超名冊交叉比對 —— 這 36 支裡有 12 支
  (BUR COV HUL IPS LEE LEI LUT SHU SOU SUN WHU WOL)本站已經有資料,
  **你交回來的必須跟既有的一致**。不一致代表其中一邊錯了,我會整批回頭問你,
  不會自己挑一個。這 12 支等於是給你的一組對照題。

### 不需要你做的

- 球員名單、球員數據、xG —— 英冠沒有免費來源,本站已經決定不做這一層,
  不要為了補齊而去找付費來源或人工整理。
- 教練 —— 另外一份提示詞,不要混在這一份裡交。
- 中文隊名 —— 本站已經有了。
