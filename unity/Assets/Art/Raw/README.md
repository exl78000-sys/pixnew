# 素材放置說明(給製作人)

把 `C:\Users\Gon\Desktop\素材` 資料夾裡的內容**整包複製到這個資料夾**(`unity/Assets/Art/Raw/`)。

- 這個資料夾已設定不進版控(素材包授權多半禁止再散布)。
- Unity 會自動匯入圖檔;之後 M1-T1 任務會從這裡挑檔整理到 `Art/Tilesets/`、`Art/Characters/`
  並設定正確的匯入參數(Pixels Per Unit = 32、Point filter、無壓縮)。
- 字型(如 Cubic 11 的 .ttf)請放到 `unity/Assets/Art/Fonts/`。
- 授權頁截圖存到 repo 的 `docs/licenses/`。
