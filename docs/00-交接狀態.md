## 2. 本 session 建立的架構(接手前先懂這些)

- **公寓場景是生成的,不是手拼的**:佈局唯一來源 = `unity/Assets/StreamingAssets/content/apartment-layout.json`
  (房間矩形/牆段與門洞/家具圖集座標/互動點)。改佈局 → 改 JSON → Unity 選單
  **Tools → Pixnew → Build Apartment Scene (P-03)** 重跑。磚資產在 `Art/Tiles/apartment_tiles.asset`(生成物)。
- **角色動畫也是生成的**:**Tools → Pixnew → Build Character Assets (P-04)** 從
  `Art/Characters/premade_character_32_0X.png` 切幀,輸出 `Resources/Characters/roommate_0X.controller`。
  圖集規則:頂部留白 32px,之後每 64px 一段動畫帶(幀 32x64);帶1=idle、帶2=walk;方向序 右/上/左/下、每向 6 幀。
- **執行期組裝**(場上只有產生器掛好的元件,無手工 prefab):
  `ApartmentRoot` = `ApartmentScene`(烘焙 WorldGrid)+ `GameRoot`(SimClock/LlmRouter/HUD/日夜/鍵盤)+
  `M1TestDriver`(P-04 鷹架:3 測試室友每 30 模擬分隨機走;**P-07 作息接手後應移除**)。
- **模擬核心純 C#**(`Scripts/Sim/`,僅用 UnityEngine 數學型別):WorldGrid(可走性/房間/物件點位/
  agent 移動與目的格互斥)、Pathfinder(A* 四向)。測試在 `Assets/Tests/EditMode/`(Test Runner 跑)。
- **組件結構**:`Scripts/` 掛 `Pixnew.Runtime.asmdef`(引用 UnityEngine.UI);Editor 腳本在 `Assets/Editor/`
  (屬 Assembly-CSharp-Editor,可引用 Runtime)。套件:2d.sprite / 2d.tilemap / newtonsoft-json / test-framework / **ugui**。
