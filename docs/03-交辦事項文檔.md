**M0-T2 製作人操作說明**:
1. 安裝 Unity Hub 與 Unity 2022.3 LTS 以上版本(Unity 6 亦可)。
2. Unity Hub → Add(加入專案)→ 選 repo 裡的 `unity/` 資料夾 → 開啟(首次開啟會自動建索引,幾分鐘)。
3. 把 `C:\Users\Gon\Desktop\素材` 的內容整包複製到 `unity/Assets/Art/Raw/`
   (此資料夾不進版控);字型檔(.ttf)放 `unity/Assets/Art/Fonts/`。
4. 素材授權頁截圖存到 `docs/licenses/`,並告知架構師素材包內容清單
   (包名/尺寸 16 or 32px/有無角色行走圖),M1-T1 需要這份資訊。

**M0-T4 製作人操作說明**:
1. 到 platform.claude.com 建 API key,先儲值小額(建議 $10 起)。
2. 把 `unity/Assets/StreamingAssets/config.example.json` 複製為同資料夾的 `config.json`,
   填入 key。`config.json` 已在 .gitignore,勿提交。
3. 進 Unity Play,按「測試 LLM 連線」應顯示 ✅。

## 分工原則備忘

1. **製作人的任務都不需要寫程式**:下載素材、填 key、寫人設、出事件卡點子、試玩回饋。
2. **AI 助手嚴格照提示詞執行**:提示詞裡的驗收標準即合約;有疑義先問架構師,不自行擴張範圍。
3. **架構師負責**:任務排序與依賴把關、提示詞維護、程式碼審查、把製作人的回饋轉成新任務。
4. 任何人發現文檔與現實不符 → 改文檔(本套文檔是唯一事實來源)。
