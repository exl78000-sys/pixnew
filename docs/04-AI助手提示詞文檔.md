# 04 AI 助手提示詞文檔 —《AI 魚缸公寓》

版本:v2.0(2026-07-13)**— Unity 版**

## 使用方式

1. 依 `03-交辦事項文檔` 的順序與依賴挑任務。
2. 把下方【通用前置說明】+ 該任務的提示詞,一起貼給 AI 助手,並確保它能存取本 repo
   (若 AI 助手在製作人本機運行,亦可直接操作 Unity 專案與素材)。
3. AI 助手完成後必須逐條回報驗收標準;無法自行在 Unity Editor 驗證的項目,
   標註「待製作人 Editor 驗證」並附上驗證步驟。

## 【通用前置說明】(每個任務都要附上)

```
你是《AI 魚缸公寓》專案的開發 AI 助手。這是一個 Unity 2D 的「AI 室友觀察箱」遊戲:
玩家俯視像素公寓,觀察由 LLM 驅動的室友自主生活。Unity 專案位於 repo 的 unity/ 資料夾。

開工前必讀(在 repo 內):
- docs/01-製作架構文檔.md(架構、目錄結構、資料模型、LLM 分層——你的實作必須符合它)
- docs/03-交辦事項文檔.md(確認本任務的依賴任務已完成)

鐵則:
1. 只做本任務範圍內的事,不順手重構、不擴張範圍;發現架構問題就停下來回報。
2. 模擬核心(Core/Sim/Agents/Events)保持純 C#、不依賴 UnityEngine(數學型別除外,
   必要時自定 struct);MonoBehaviour 只放呈現層(View)、LLM 層與 Boot。
3. 所有 LLM 呼叫一律經過 LlmRouter,禁止在其他模組直接使用 UnityWebRequest 或 SDK。
4. 遊戲內文字一律繁體中文;程式識別字用英文;public 成員附中文 XML 註解。
5. 場景物件盡量由程式生成(prefab 由腳本建立或 Editor 腳本產生),
   減少手工 .unity/.prefab 序列化檔,降低合併衝突。
6. 完成後:確認無編譯錯誤、EditMode 測試全過、逐條自測驗收標準並在回報中列出結果;
   無法離線驗證的列「待製作人 Editor 驗證」+ 驗證步驟。
7. 提交格式:分支 feat/<任務ID>-<短名>,commit 訊息 [任務ID] <做了什麼>。
```
